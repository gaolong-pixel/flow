# 7.3d-2 Timer 生命周期与 Controller 集成

## 实现

- 双端 TimerEngine 增加 Pause/Resume/Cancel/Poll/Completion Plan/Commit。
- Resume 使用独立 deadline anchor；同一 PAUSED 周期固定，失败不清除。
- Controller 事务预构造 Session/Scheduler/ActiveTimerReference 候选，Engine commit 后只发布。
- TIMER→TIMER 使用同一 CompletionPlan 一次 commit 结束旧 run、启动新 run。
- COUNT→TIMER 使用 prepareStart/commitStart。
- 自动到期通过 Controller poll 驱动；重复 poll 幂等。
- SKIP 到期优先；CANCEL 到期先完成当前 TIMER 再取消剩余流程。
- ActiveTimerReference 校验 sessionId、轮次、步骤、runId。

## 测试/结果

当前全量 Android 350 tests、iOS 351 tests，0 failures。
覆盖 pause/resume、到期、TIMER→TIMER、TIMER→COUNT、CANCEL、SKIP、旧 runId、revision 等。
