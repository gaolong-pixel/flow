# 7.3d-4 并发竞争与异常处理

## 实现

- Android Controller 全事务 `synchronized(lock)`；iOS `@MainActor`，事务内无 await。
- 同一 expectedRevision 并发操作最多一个成功。
- revision 溢出在 Engine commit 前检查，返回 `REVISION_OVERFLOW`。
- 旧 revision、旧 runId、旧 stepKey 隔离。
- SKIP 使用 expiry-sensitive CompletionPlan，在 Engine commit 时刻决定 COMPLETED/SKIPPED。
- Controller 预构造两套候选，一次 commit、一次 revision。
- 失败不发布 Session/reference/revision。

## 测试/结果

- Android `ExecutionControllerConcurrencyTest`：14 tests，0 failures。
- 双端并发/到期竞争测试通过；全量 Android 350、iOS 351，0 failures。
